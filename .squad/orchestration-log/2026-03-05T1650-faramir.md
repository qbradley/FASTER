### Recommendations for Rust

- **Simplify API:** Reduce to 3-4 type parameters using associated types

- **Unified Async:** Use async/await instead of ValueTask + callbacks + manual pending
- **RAII Safety:** Epoch guards via scope guards (!Send marker for compile-time safety)
- **Builder Pattern:** Unified configuration instead of mixed high/low-level APIs
