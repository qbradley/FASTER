2. **ci** — 3-OS matrix (ubuntu-latest, windows-latest, macos-latest) with stable Rust

4. **bench** — Criterion benchmarks (main-branch pushes only; no PR noise)
5. **deny** — License audit + security advisory scan (cargo-deny)

## Design Decisions

- **GitHub Actions over Azure Pipelines:** Rust CI has zero overlap with C#/C++ toolchains. Separate workflow avoids pollution and keeps concerns isolated.
- **Path filtering:** All triggers filtered to `rust/**` to prevent firing on C++/C# changes.
- **Nightly rustfmt only:** Stable Rust on other jobs balances strictness against toolchain stability.
- **Miri as informational:** Expect unsafe code to appear (atomics, pointer arithmetic); Miri should inform, not block.
- **Caching:** `Swatinem/rust-cache@v2` per-OS cache keys; keeps CI fast.
